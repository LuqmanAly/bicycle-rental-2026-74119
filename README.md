# Bicycle Rental System Luqman Ali - 74119

## Project Files

- `rental_item.py` 
- `bicycle.py` 
- `main.py` 
- `test_bicycle.py` 

## Use

- Python 3.13.1
- Python Unittest for test cases


## How to Run

1. Open a terminal.
2. Navigate to the project directory.
3. Run the following command to execute the main program:

   ```bash
   python main.py
   ```

The program demonstrates bicycle creation, borrowing, returning, price updates, rental cost calculation, and error handling.

## How to Run Tests

Run the following command to execute the automated unit tests:

```bash
python -m unittest -v test_bicycle.py
```
